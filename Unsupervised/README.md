> # SUMMARY
> - This is a desktop html file for performing K-means and C-means clustering on a CSV file.
> - Currently this only works when downloaded and run with the included CSV file
> - The aim is to later implement this into a simple tool for quickly performing simple machine learning through the browser

> INSTRUCTIONS:
> 1. Double click the html file to run the program, or open it in a code editor to view the code
> 2. Load the included csv document from the zip
> 3. Select the number of clusters, which type of clustering you wish to use, and select an M-value when using C-means clustering.
> 4. After choosing your options, you must hit initialize to place the cluster markers onto the graph
> 5. You can now go through steps of either k-means or c-means using the "Step Forward" option (and can seamlessly switch between the two)
> 6. You can also skip to the end using the "Skip to End" option
	
NOTE:
Check DI validity currently does not work properly

Please enjoy!
